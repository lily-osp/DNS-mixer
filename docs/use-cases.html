Implementation Examples

Router Integration

Step-by-step router configuration:

  1. Access router admin panel (192.168.1.1)
  2. Navigate to DNS/Network settings
  3. Set Primary DNS to DNS-Mixer IP (192.168.1.100)
  4. Leave Secondary DNS blank
  5. Save and reboot router

Result: All devices on network automatically use DNS-Mixer

Device-Specific Setup

Individual device configuration:

  1. Open network settings on device
  2. Find DNS configuration section
  3. Set DNS server to 192.168.1.100
  4. Save settings
  5. Test with DNS lookup

Result: Specific device uses DNS-Mixer bypass capabilities
